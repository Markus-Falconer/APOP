Model notes

  • Ported from the team's Python script (CoolProp + Cantera). Gas properties use NASA 7-coefficient polynomials (GRI-Mech 3.0) for N₂, O₂, CO₂ and H₂O as ideal-gas mixtures.
  • Combustion is complete lean burning of n-dodecane at constant pressure and enthalpy. This matches Cantera's equilibrate('HP') closely for lean mixtures, where dissociation is negligible; it is not valid above φ = 1.
  • Mass flow downstream of the combustor is air plus the fuel flow computed from the consumption input, as in the Python. With "compute φ from fuel flow" off, φ is set independently, just as the script does.
  • Generator shaft power = electrical power ÷ generator efficiency, taken from the turbine on top of compressor work. Fuel flow and φ stay fixed, so turbine inlet temperature does not rise. On the real engine the ECU adds fuel to hold speed under load. Raise the fuel flow to study that case.
  • All calculations run in SI units. The unit selector only converts what is displayed and what you type in, so switching units never changes the result. Your unit choice is remembered in this browser.
  • The compressor exit temperature uses constant γ, as in the script; compressor work uses the variable-property enthalpy.
  • EGT is reported at the turbine exit (station 4, stagnation), where the ECU thermocouple sits. The original script printed the nozzle-exit static temperature, which reads about 80 °C lower.
  • This page is a direct port of the original script. For the version calibrated to engine test data, with the measured nozzle and the generator load, see Cycle analysis V2.
