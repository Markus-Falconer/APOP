From Ben's CAD to a cycle analysis

This page reads a STEP or IGES export of the Big Ben duct, measures the features the Big Ben model needs straight off the CAD surfaces, and runs the same cycle model as the V3 page on them. Nothing is typed in by hand unless the CAD doesn't show it.

  1. Export from NX. File → Export → STEP (AP214 or AP242 both work). Export the duct parts, or the whole assembly; fasteners only slow it down. NX's native .prt can't be read outside NX, which is why STEP is needed.
  2. Open it here. Use the button on the left, or drop the file on the viewer. The page finds the planes, cylinders, cones and pipe bends among the faces and makes a first guess at each feature.
  3. Check the tags. Each feature is coloured on the model. If one is wrong, press Pick and click the right face. Clicking any face also shows its size and shape.
  4. Fill in what the CAD can't show. That's the hub, guide vanes, window edges and the load, on the left. The measured values sit in section 2, where any of them can be overridden.

6. How the measuring works

  • Reading. The file is opened with OpenCascade (the geometry kernel behind FreeCAD) compiled to run in the browser. It keeps each CAD face separate, so every face can be measured on its own. Units come from the file and are converted to mm.
  • Face shapes. Each face's surface normals say what it is: all parallel is a flat face; all square to one direction is a cylinder or a cone about that direction; neither is tried as a pipe bend (stepping each point inward by the tube radius lands it on the bend's centreline arc). Radius, axis and cone angle come from least-squares fits.
  • Walls. For a tube or pipe the page finds the coaxial face on the other side of the wall, so the inside diameter and wall thickness come out whichever side was clicked.
  • Frame. The tube bore gives the engine axis. The flange (or, without it, the way the pipe leaves) says which way is aft, and x = 0 is at the flange. The first pipe's direction is +y.
  • Model inputs. Pipe angle is between the pipe and engine axes. The window centre is where the pipe centreline meets the bore. The gap is twice the leg's distance from the axis less the pipe's outside diameter. The bend radius comes from where the straights end (exact when the bend is tangent to them), cross-checked against the bend surface. Exit ID is the smallest diameter of the neck cone.
  • Accuracy. Planes, cylinders and cones come out within a few thousandths of a mm. Bends are read off the faceted surface, so their radius is good to about 1% and their angle to about a degree; that is why the straights are used when they agree.
  • What the model still assumes. Both legs are mirror images in one plane through the axis, the pipe centrelines meet the engine axis, and the motor box, necks and exits sit where the V3 layout puts them. The checks in section 2 flag a CAD that doesn't fit those assumptions. Everything else (losses, the engine match, the wheel) is the V3 model unchanged, so the same caveats apply.
  • The example is the V3 page's Ben's-layout preset written out as a surface model (tools/make-example-step.js in the repository), so its measured values should match that preset exactly.
